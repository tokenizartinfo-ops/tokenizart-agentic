# MCP Distribution

`server.preview.json` describes the protected experimental Tokenizart public
read-only MCP surface. It is intentionally not named `server.json` because the
server has not passed the production and MCP Registry release gates.

Current namespaces:

- `knowledge.*`: Nivel 5 verified discovery and retrieval.
- `gallery.*`: sanitized public artwork and Certify traceability links.

Owner context and execution are not part of the public server.
