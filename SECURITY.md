# Security Policy

## Scope

Security reports may cover the public CLI, schemas, Agent Skills, MCP
contracts or public Tokenizart endpoints referenced by this repository.

## Reporting

Send a concise report to `tokenizart.info@gmail.com` with:

- affected component and version;
- reproducible steps using synthetic data;
- expected and observed behavior;
- impact and any safe mitigation.

Do not include private keys, wallet recovery material, passwords, production
tokens, raw user data or active exploit payloads in GitHub issues.

## Safe research boundary

Do not perform Mint, Certify, transfer, voucher, privacy, NFC, upload, wallet
or administrative mutations. Do not degrade service availability or access
data outside your authorization. Tokenizart will coordinate a controlled test
when live verification is necessary.
