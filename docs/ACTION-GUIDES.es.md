# Guias publicas de acciones Atelier

Estas guias Nivel 5 combinan una explicacion humana, micro-pasos consumibles por
agentes y referencias visuales al Manual Atelier. Son educativas y read-only:
no ejecutan Mint, Certify, transferencia, vinculacion NFC, cambios de vouchers,
privacidad, uploads ni firmas de wallet.
