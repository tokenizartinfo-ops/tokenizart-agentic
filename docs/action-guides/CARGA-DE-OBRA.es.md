# Carga de obra en Atelier

Esta guia explica el recorrido general sin ejecutar acciones ni leer una cuenta.

## Antes de empezar

- Crear o acceder al usuario de Atelier.
- Tener al menos un titulo para identificar la obra.
- Preparar imagen principal y datos tecnicos disponibles.
- Decidir que informacion conviene mantener privada y cual podria mostrarse.

## Secuencia

1. Abrir la administracion de obras propias o gestionadas, segun el rol.
2. Iniciar la carga y completar los datos principales.
3. Incorporar imagenes y documentacion disponible.
4. Completar la ficha tecnica de manera progresiva.
5. Revisar privacidad y visibilidad antes de guardar.
6. Confirmar que la ficha representa correctamente la obra.
7. Guardar la precarga. Mint es un paso posterior y requiere una revision separada.

No todos los datos son obligatorios para comenzar. Una ficha mas completa mejora
la informacion disponible y facilita la trazabilidad posterior.

## Limite

Los nombres exactos de botones y campos pueden cambiar. Verifica la interfaz
activa antes de usar esta guia como instruccion literal.
