# Public Knowledge

Notas publicas `Nivel 5` curadas para Companion Beta Nivel 5 y Copilot Nivel 4.

Objetivo: que el sistema conversacional responda preguntas amplias sobre Tokenizart, Atelier, filosofia, arquitectura tecnologica/legal, valor diferencial, roles, vouchers, Smart Wallet, transfer y trazabilidad sin caer en flujos operativos equivocados.

Estas notas prevalecen sobre salidas NotebookLM ambiguas, obsoletas o contradictorias. NotebookLM se usa como fuente auxiliar; la respuesta publica de produccion debe recuperar estas sintesis `verified`.

## Reglas de uso

- Responder primero la pregunta real del usuario.
- No saltar a Mint, Certify, NFC o vouchers si el usuario pregunta por vision, valor diferencial, precio, blockchain general o comparacion con otras plataformas.
- No describir Tokenizart como marketplace NFT generico.
- No prometer venta, liquidez, precio, autenticidad absoluta, seguridad absoluta, derechos de autor, escrow activo o asesoramiento legal.
- Usar lenguaje humano, didactico y breve; despues ofrecer un solo siguiente paso.
