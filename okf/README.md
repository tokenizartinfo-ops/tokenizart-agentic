# Tokenizart Public OKF

This directory contains deterministic, read-only OKF v0.2 exports derived from
verified Tokenizart Level 5 knowledge. Obsidian and private GitHub repositories
remain the editorial authority.

Each versioned bundle is generated by `tokenizart-hermes`; do not edit generated
concepts manually. Rebuild from canonical sources and review the exclusion
report instead.
