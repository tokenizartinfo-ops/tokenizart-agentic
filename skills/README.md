# Skills públicas de Tokenizart y Atelier

Estas skills enseñan a un agente a orientar al usuario con fuentes públicas verificables. Cargarlas no concede acceso a una cuenta ni habilita operaciones. Para datos personales, el agente necesita una conexión autorizada a la aplicación correspondiente.

| Intención | Skill |
| --- | --- |
| Descubrir el producto y el conocimiento público | [Conocimiento público](tokenizart-public-knowledge/SKILL.md) |
| Elegir la guía adecuada según la pregunta | [Guía de usuario de Atelier](tokenizart-atelier-user-guide/SKILL.md) |
| Comprender la cuenta y Smart Wallet | [Cuenta y wallet](tokenizart-atelier-account-wallet/SKILL.md) |
| Cargar y preparar una obra | [Preparación de obra](tokenizart-atelier-artwork-preparation/SKILL.md) |
| Adquirir y entender vouchers | [Vouchers](tokenizart-atelier-vouchers/SKILL.md) |
| Hacer Mint individual o por lote | [Mint](tokenizart-atelier-mint/SKILL.md) |
| Solicitar o realizar Certify | [Certify](tokenizart-atelier-certify/SKILL.md) |
| Vincular un dispositivo NFC | [NFC](tokenizart-atelier-nfc/SKILL.md) |
| Comprender una transferencia | [Transferencia](tokenizart-atelier-transfer/SKILL.md) |
| Decidir la visibilidad pública | [Visibilidad](tokenizart-atelier-visibility/SKILL.md) |
| Verificar una obra pública | [Trazabilidad de Gallery](tokenizart-gallery-traceability/SKILL.md) |
| Explorar un recorrido sintético | [Demo Atelier](tokenizart-demo-atelier/SKILL.md) |

Las guías de acciones describen flujos; no constituyen comandos ejecutables. Véase la [caja de herramientas y matriz de capacidades](../docs/ATELIER-LLM-TOOLBOX.es.md).
