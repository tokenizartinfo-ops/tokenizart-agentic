# Prepare an artwork in Atelier

Access: Nivel 5 guidance. Mode: read-only.

## Use

1. Ask whether the person is preparing their own artwork or one they manage if that distinction affects the next step.
2. Gather a title or identifier, a principal image, technical details and supporting evidence the person actually knows. Mark unknown provenance as unknown.
3. In the signed-in Atelier interface, locate the appropriate own or managed artwork area, enter the information, review visibility and save the preload.
4. Review the saved record before discussing Mint. Preloading is not Mint and creates no token by itself.
5. If a field or button differs from the guide, use the current screen rather than inventing an exact control name.

Sources: [public artwork-loading guide](https://github.com/tokenizartinfo-ops/tokenizart-agentic/blob/main/docs/action-guides/CARGA-DE-OBRA.es.md), [Atelier manual, pages 60–66](https://tokenizart.com/wp-content/uploads/2024/04/Atelier-Manual-del-Usuario-1.pdf#page=60), [public action map](https://github.com/tokenizartinfo-ops/tokenizart-agentic/blob/main/docs/ACTION-GUIDES.es.md).

This skill cannot inspect a private work, upload media or save a draft. For a specific work, use only a verified authorized owner connection; never infer its state from a public example.

Never execute Mint, Certify, transfers, voucher changes, privacy changes,
NFC binding, uploads or wallet signing.
