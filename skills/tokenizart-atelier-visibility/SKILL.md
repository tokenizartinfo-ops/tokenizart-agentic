# Visibility and public Gallery

Access: Nivel 5 for what is already public; private settings are Nivel 4. Mode: read-only.

First identify whether the person wants to view a public artwork, decide what to show, or change visibility for their own record. For a public artwork, use `tokenizart-gallery-traceability` and only the fields currently visible. For a privacy decision, guide the owner to inspect the current signed-in Atelier controls and preview the public result before confirming. Do not assume that hiding a page erases earlier blockchain facts or third-party copies.

An agent may explain that Gallery visibility is owner-controlled and that per-Certify evidence can have its own visibility. It cannot infer hidden evidence from a public token or change a setting through this skill.

Sources: [public Tokenizart/Atelier guide](https://tokenizart.com/es/tokenizart-y-atelier-guia-publica-y-descubrimiento-agentico/), [Gallery traceability skill](https://github.com/tokenizartinfo-ops/tokenizart-agentic/blob/main/skills/tokenizart-gallery-traceability/SKILL.md), [public Atelier Demo repository](https://github.com/tokenizartinfo-ops/tokenizart-atelier-demo) for synthetic practice only.

No current-button instructions are asserted here. A real privacy change requires the authenticated owner's deliberate action and result check.

Never execute Mint, Certify, transfers, voucher changes, privacy changes,
NFC binding, uploads or wallet signing.
