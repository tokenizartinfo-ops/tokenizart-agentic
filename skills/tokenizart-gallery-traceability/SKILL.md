# Tokenizart Gallery Traceability

Access: Nivel 5. Mode: read-only.

## Use

1. Identify the public artwork or public blockchain reference.
2. Read only the public artwork, Certify and traceability surfaces exposed by Tokenizart.
3. Explain what each icon or link proves and what it does not prove.
4. Preserve the source URL, chain, contract, token ID and transaction reference when verified.
5. Do not infer hidden owner data or unpublished evidence.

Treat Gallery visibility as owner-controlled. A blockchain record supports
traceability; it does not transfer copyright or guarantee authenticity, value
or physical delivery by itself.

Never execute Mint, Certify, transfers, voucher changes, privacy changes,
NFC binding, uploads or wallet signing.
